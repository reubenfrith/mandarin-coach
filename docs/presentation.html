06 · Evals — does it actually work?

What we measured · good · bad.

What we measured
  • ·Corrections — the agent vs a naked LLM (60 cases)
  • ·Retrieval — does it fetch the right grammar rule?
  • ·The memory writer — right error logged, never a clean one?
  • ·Voice routing & pronunciation tone-scoring
✓ What was good
  • ✓10/10 vs 7/10 — remembering at scale (the thesis)
  • ✓97% vs 82% correct fixes, zero misleading
  • ✓1.00 logging precision — text & tone
  • ✓Called the right tool 99% of the time
△ What was honestly weak
  • △On one-off fixes it’s ≈ a plain LLM — the edge is memory
  • △Declines only 2 of 4 off-topic questions

Every judged number is paired with a deterministic cross-check — when they disagree, the deterministic one wins.
